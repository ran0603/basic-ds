basic-ds

A lightweight, Sass-based CSS design system — components, utilities, and design tokens.

Area Useful Components & Classes
Forms .input, .textarea, .select, .check-group, .radio-group, .switch, .form-label, .form-hint, .form-error, .is-error
Feedback .alert (success, error, warning, info), .badge (variants + dot), .toast, .spinner, .progress, .empty-state
Navigation .navbar, .sidenav, .breadcrumb, .tabs, .pagination, .menu
Content .card (header, body, footer, hover), .accordion, .table-wrap, .table, .list, .avatar, .divider, .tooltip
Actions .btn (primary, secondary, accent, ghost, link, icon), sizes (.btn--xs to .btn--xl), .btn--full, .btn-group
Layout .container, .stack, .cluster, .flex-grid (.col--1 to .col--12), spacing tokens
Utilities .hidden, .sr-only, text alignment, .truncate, .border, .rounded, .shadow-sm / .shadow-md, .z-10 to .z-50
